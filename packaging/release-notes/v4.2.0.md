## EShot v4.2.0

### Annotation and OCR

- Added corner handles to stretch selected text, with Shift for proportional text scaling
- Tightened text hit testing so drawing near text no longer unexpectedly selects it
- Restored capture shortcuts after text editing and other toolbar interactions, including Escape, copy, undo, and redo
- Hold Shift while using the highlighter to lock the stroke to the nearest horizontal or vertical axis
- Added a short in-canvas hint for the highlighter axis lock
- Added a Translate action to OCR results that opens recognized text in Google Translate using the default browser

### Recording

- Fixed completed Wayland GStreamer video recordings being discarded after Stop
- Improved microphone-device control sizing in the recording setup panel
- Added a notification fallback when the desktop tray is unavailable

### GNOME and Linux

- Added a compact trayless control window with Capture, Settings, About, and Quit for GNOME users without a tray extension
- Kept autostart silent while allowing a normal application launch to open the control window
- Improved the GNOME AppImage first-launch guidance and documented stock GNOME file-manager behavior
- Warmed the XDG Desktop Portal at startup to avoid its multi-second cold-start delay before the first capture
- Documented that GNOME's secure Screenshot portal can still add a short selection-panel delay that varies by GNOME and portal version
