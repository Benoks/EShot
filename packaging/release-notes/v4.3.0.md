## EShot v4.3.0

### First launch and AppImage setup

- Fixed a Linux first-run race where the capture overlay could remain visible behind the Welcome window
- Kept overlay prewarming for normal launches while postponing it until the Welcome flow has closed on first launch
- Clarified that the AppImage is portable and does not install EShot merely by being opened
- Documented the optional application-menu integration path, including the managed AppImage location and when the original download can be removed

### Documentation and testing

- Improved the AppImage integration hint in the first-run setup
- Added a regression test for deferring overlay prewarming during first-run onboarding
