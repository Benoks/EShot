## EShot v4.6.0

### Recording

- **Pause no longer leaves a frozen frame.** Paused time is cut from videos and Wayland GIFs, and on Windows desktop audio is not recorded while paused
- The start delay now shows a countdown over the selected region. Esc, the cancel button, the cancel hotkey or the tray menu stop it. On Wayland the screen picker opens before the countdown
- Quitting EShot during a recording (tray, `--quit`, an update) stops and saves the recording first instead of leaving a broken file
- Long Wayland GIFs are converted in two passes with a time limit that grows with the recording. If conversion fails, the recorded video is kept and its location is shown
- A video saved without system audio or microphone now says so in the notification
- Wayland GIF recording checks for FFmpeg before it starts
- Recording errors show the actual GStreamer error

### Hotkeys

- If another app holds an EShot hotkey, EShot now tells you which key could not be registered, and the tray tooltip shows the key that actually works
- Settings warns when two EShot actions use the same key and won't save until it is fixed

### Text and capture overlay

- Starting a new selection or right-clicking while typing no longer leaves the text box open and stamps its text into the next capture
- Undo/redo while editing a label no longer edits a different label
- Moving the editor of an existing label moves the label; Enter after committing text copies again
- Tool shortcuts remember the last tool like toolbar clicks; double-click edits labels in a locked selection
- The text panel stays on screen, pinned images open exactly over the captured area, and the hint strip shows your configured copy/save keys

### Linux

- KDE Wayland: sharper captures on mixed-DPI setups, each screen is captured at its own resolution (#36, thanks @100pangci)
- **Fedora:** dependency setup uses Fedora's own package names (`ffmpeg-free`, ...) and skips packages that aren't in the enabled repositories instead of failing. MP4 recording needs RPM Fusion
- The package installer no longer gives up after 25 seconds while you confirm the install, and menu integration happens even if the package step fails
- **New: Settings → Remove EShot** (or `eshot --uninstall`) gives Print Screen back to GNOME/Spectacle and removes the menu entry, icons, autostart and the integrated AppImage
- The README and the first-run screen now warn not to hand the AppImage to Gear Lever, AppImageLauncher or an updater: the AppImage installs and updates itself
- AppImage updates refresh the menu entry and no longer leave a backup copy behind; GNOME on Ubuntu/Fedora gets the tray extension

### Windows

- Uninstalling a per-user install also removes the "Start as administrator" task
- FFmpeg, Tesseract and OCR language downloads in Settings are verified with SHA-256 before they are installed

### Other fixes

- Every language now has the setup, package and shortcut messages that used to be Turkish/English only, and Turkish text uses proper characters
- No "Update failed" message when starting offline; a silent update waits until no recording is running
- Closing Settings during a download no longer shows a false error or breaks the component install
- Reset keeps the first-run state, `--save` no longer overwrites that file on a later save, and the black tray icon setting applies while an update is pending
