## EShot v4.3.1

### KDE first-run setup

- Fixed the KDE Print Screen setup flow: EShot now removes only Spectacle's plain Print Screen shortcut before registering its own shortcut
- Restores Spectacle's original shortcut if EShot cannot claim Print Screen
- Improved the first-run conflict message so it directs KDE users to **Use Print Screen for EShot** or another shortcut

### Linux desktop support guidance

- Added a red first-run warning for unsupported Linux desktop environments and compositors
- Added a lighter warning for KDE Plasma or GNOME sessions running outside Wayland
- Added regression coverage for desktop support classification and KDE shortcut restoration
