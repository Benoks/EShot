## EShot v4.9.0

### Capturing

- **Capture Last Region** in the tray menu, with an optional hotkey (Settings → Hotkey): the overlay opens with the region you last copied or saved already selected. Press Enter to copy it again, or draw and adjust first. Handy for documenting a process step by step. (#46)
- **Tray icon click** setting (Settings → Capture): a left click can start a capture instead of opening the menu. A right click always opens the menu. (#45)
- **Locked selection stays editable:** the lock now only stops a click outside from starting a new selection. You can still resize it from the edges and corners and move it. Double-click outside to start over. (#44)

### Pinned images

- **Borderless:** no title bar anymore. The close button and size only show while you hover. Double-click or Esc closes a pin, drag moves it, the corners resize it. (#43)
- **Sharper when resized:** pins are scaled smoothly from the original image, so small text stays readable. (#43)
- Hovering a pin shows a tooltip with all its controls.

### Other

- Resetting the settings now also clears the Capture screen now hotkey.
- The shortcut sheet (?) and README list the new keys and actions.
