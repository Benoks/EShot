## EShot v4.5.0

### Blur and pixelate

- **Blur (B)** is now a smooth, Gaussian-style blur (#35)
- **Pixelate (M)** is a separate tool for the mosaic effect, the safer choice for hiding sensitive text
- Pixelate blocks now show the average colour of the area they cover, stay square, and no longer shift while a region is drawn or resized
- Both tools use the strength slider in the Quick Settings tab on the left; the extra slider next to the toolbar was removed

### Text

- Edit an existing label by double-clicking it, clicking it with the Text tool, or pressing F2
- New text options: bold (Ctrl+B) and a background style that switches between box, plain and outline
- Ctrl + / Ctrl − change the text size while typing
- Clearing a label and confirming removes it; every edit is one undo step

### Selecting and editing objects

- Drawing tools now always draw, even over other objects, instead of selecting the object and dropping the tool
- Drag the selected object to move it, or Ctrl+click any object to select and move it while keeping the current tool
- Delete or Backspace removes the selected object
- Choosing a colour while an object is selected recolours it

### Getting started

- Press **?** or F1 during a capture, or use the new button at the bottom of the right-hand panel, to see every shortcut and mouse gesture
- The first few captures show a short hint strip and point out the Quick Settings tab
- One-time tips explain text editing and Ctrl+click; Settings can show them again
- Toolbar tooltips now show each tool's configured shortcut and what it does
- Fresh installs show a tray notification with the capture shortcut once setup finishes

### Icons and fixes

- New icons for blur, pixelate, highlighter, circle, semi-transparent rectangle, video, eyedropper and eraser
- Shortcut names are shown as Ctrl/Shift/Alt in every language instead of following the system language
