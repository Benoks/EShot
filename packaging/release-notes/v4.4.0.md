## EShot v4.4.0

### Windows: no more administrator prompt

- EShot now runs as the signed-in user instead of requesting administrator rights on every launch, so settings stay with your own account on machines that use a separate admin account (#33)
- The installer defaults to a per-user install that needs no administrator permission. An all-users install is still available; existing all-users installs stay in that mode when updated
- Auto-start now uses a per-user startup entry. The old elevated startup task is migrated automatically and, if it is still present, can be switched off from Settings
- FFmpeg and OCR components can be downloaded even when EShot is installed in Program Files; they are stored in your user profile instead
- Updates keep the current install mode, verify the installer again right before it runs, and always reopen EShot, even if the update is canceled
- Portable copies open the release page instead of installing a second copy
- Windows may still restrict capture or keyboard focus over elevated applications and the UAC secure desktop

### Capture and annotation

- Fixed white crosshair lines that could stay on screen at fractional display scales such as 125% or 150% (#34)
- Blur regions keep the strength they were drawn with, so changing the blur slider can no longer weaken an earlier blur and reveal hidden content
- Double-clicking inside a selection no longer clears annotations and selects the whole monitor
- Ctrl+C and Ctrl+S do nothing until a region is selected
- Text that is still being typed is kept when you copy, save, pin, upload, run OCR or start another text label
- Fixed selecting and resizing scaled or rotated text, Shift-drawn circles, and selection after undoing an erase
- Undo history no longer resets after 200 steps
- Error dialogs and the color picker no longer lose key presses to the capture overlay
- OCR uses your saved language on the first run and re-runs whenever the language changes; Translate keeps characters such as "+"

### Recording

- Fixed corrupted GIFs when a recording contains few colors, such as terminals, editors and flat interfaces
- GIFs recorded at 15 or 30 FPS now play at the correct speed
- Fixed GIF recording of the wrong area on scaled X11 displays
- Pressing Stop repeatedly or reaching the time limit no longer discards a Linux recording while it is being finalized
- Windows system audio: videos are no longer cut short when nothing is playing, the desktop audio volume setting is applied, canceled recordings no longer leave hidden temporary files, and a failed start no longer crashes the next recording
- GIF and video recordings can no longer run at the same time

### Shortcuts and settings

- GNOME without the GlobalShortcuts portal: custom capture shortcuts work again, and changing recording or direct-capture shortcuts no longer blocks saving Settings
- Super-key shortcuts are sent to the shortcuts portal in the standard format
- If a shortcut cannot be registered, Settings restores the previous shortcuts instead of leaving them half applied
- Reset restores every shortcut to its default immediately
- Settings export and import now include the visual search provider and window size option
- Upload credentials show a warning when they could not be stored securely
- Only one Settings window opens at a time
- Linux first-run setup no longer changes your saved language, and it is no longer interrupted when a capture is requested
- Settings changed in the capture overlay are saved when EShot quits
