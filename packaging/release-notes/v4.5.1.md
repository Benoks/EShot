## EShot v4.5.1

### Windows: optional "Start as administrator"

- New **Start as administrator** setting (Settings → General) for capturing apps that run as administrator. Since 4.4.0 EShot runs as the signed-in user, and Windows keeps it from capturing or taking input over elevated apps
- Turning it on asks for administrator approval once. After that, EShot starts as administrator without prompting, both at login (when auto-start is on) and when opened from the Start menu
- Turning it off removes the elevated startup task and returns to the normal per-user start
- Off by default. Not recommended if you use a separate administrator account, since EShot's settings would then be stored in that account
