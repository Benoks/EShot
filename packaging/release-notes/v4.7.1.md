## EShot v4.7.1

### Windows recording fix

- Fixed video and GIF recordings failing right after pressing Start with "Option thread_queue_size … cannot be applied to input". This happened when an FFmpeg from an earlier EShot installation was still in use after updating to 4.7.0.
- The installer now replaces an FFmpeg left by an older version, so recordings always use the bundled, tested FFmpeg build.

If Windows Security's *Controlled folder access* blocks saving recordings, allow `ffmpeg.exe` from the EShot folder as well: the video file is written by FFmpeg, not by `EShot.exe`.

### Other changes

- Automatic update checks no longer show an error when GitHub returns an invalid response; failed checks are written to the log instead.
- Updated README screenshots.

Windows x64, Windows ARM64 and Linux x86_64 packages are provided below.
