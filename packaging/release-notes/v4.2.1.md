## EShot v4.2.1

### Application launch and updates

- Opening EShot from the application list, Start menu, or desktop shortcut now shows the compact Capture, Settings, About, and Quit control window on Windows, KDE Plasma, and GNOME
- Autostart remains silent and tray click behavior is unchanged
- EShot can now silently update only self-managed Windows installations and integrated AppImages that are at least two stable releases behind
- Manual update checks remain available for every supported installation type

### Security and Linux packaging

- Moved Google Drive and Yandex Disk OAuth tokens out of EShot's plain-text settings file
- OAuth tokens now use Secret Service on Linux and Windows Credential Manager on Windows
- Existing plain-text OAuth tokens are migrated and removed from settings on first use
- Removed a machine-specific Linux desktop launcher from the repository
