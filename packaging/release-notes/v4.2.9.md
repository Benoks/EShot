## EShot v4.2.9

### Capture and overlay input

- Fixed overlay number fields so a single click selects the current value and keyboard input replaces it correctly
- Extended keyboard input routing to quick settings, recording settings, text size, font selection, and other visible overlay fields
- Kept overlay input controls responsive while the inline text editor is open on KDE/GNOME XWayland sessions

### Recording

- Prevented the blue selection border from appearing inside full-screen recordings on capture backends that cannot exclude overlay windows
- Kept the recording drawer FPS, duration, and quality fields directly editable in addition to their arrow controls

### Linux and documentation

- Made the local Linux runner use the same XWayland multi-monitor overlay path as packaged KDE and GNOME builds
- Restored executable permissions for the documented local build and run scripts
- Updated Linux support documentation to mark KDE Plasma 6 and GNOME Wayland as supported, with GNOME noted as less broadly tested
- Documented Windows window selection capture in the feature list

### Tests

- Added regression coverage for overlay keyboard routing, single-click value replacement, full-screen recording borders, recording drawer inputs, and the local multi-monitor runner
