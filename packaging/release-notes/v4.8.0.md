## EShot v4.8.0

### Fullscreen games and capturing

- **Fixed the capture overlay freezing over fullscreen games** on KDE Plasma Wayland: EShot now takes focus when the overlay opens, so the game releases the mouse and keyboard. If input is still held elsewhere, a banner tells you how to cancel.
- **New "Capture screen now" hotkey** (Settings → Hotkeys, off by default): saves the screen under the mouse right away, without the selection overlay. The most reliable way to take screenshots in games. Also available in the tray menu.
- Pressing the capture hotkey again while the overlay is open now cancels it.
- Pressing Print Screen twice quickly no longer starts two captures at once.
- **Windows:** the desktop grab is checked for errors and uses Desktop Duplication over exclusive fullscreen games, instead of showing a black or garbled overlay.
- Pinned images have the right size on mixed-DPI setups and resize from the dragged corner.
- `%T` (window title) in file names is filled on Linux where possible, and dropped cleanly otherwise.
- Lower memory use for captures on multi-monitor KDE setups.

### Recording

- A selected microphone that is unplugged no longer makes every recording fail; it is skipped with a warning and shown as "not connected".
- Wayland: audio or source errors are no longer blamed on the hardware encoder; options the installed PipeWire/GStreamer does not support are left out instead of failing the recording.
- Windows: if a hardware encoder fails, recording retries with Desktop Duplication and software encoding before falling back further; system audio follows a change of the default output device (headphones, Bluetooth).
- Recordings interrupted on X11 keep their footage; Linux temporary files are hidden and cleaned up.
- Stopping right after starting is treated as cancel, not as an error. Clearer messages for portal timeouts and missing components.

### Hotkeys, updates and settings

- **KDE:** recording shortcuts are now really released when a recording ends.
- **Windows:** holding a hotkey no longer repeats it.
- Pressing Print Screen no longer discards an open Settings window: it is hidden during the capture and comes back with your changes. OCR and upload windows are kept.
- An update never interrupts a recording: it waits until EShot is idle, and the download is verified again right before installing.
- Autostart: on Linux any EShot autostart entry is recognised and updated; on Windows Task Manager's "disabled" state is respected and Settings opens without a delay.
- **Windows Security:** if Controlled folder access blocks saving, EShot explains how to allow EShot and `ffmpeg.exe` and keeps the screenshot on the clipboard.
- "Start as administrator" now warns about the security risk on per-user installs.
- `EShot --save PATH` works while EShot is already running.

### Look and feel

- Light theme and high contrast are readable everywhere; disabled controls look disabled. High contrast also applies to the capture toolbar and panels.
- The tray menu follows the theme, shows the shortcuts next to each action, and has "Open Screenshots Folder" and "Last Screenshot" entries.
- The first-run screen starts in your system language and switches language immediately.
- The GNOME control window (without tray) has Record GIF, Record Video and Open folder buttons.
- **Report a Problem** in the tray menu, About window and GNOME control window opens a GitHub issue with your EShot version and system already filled in (no personal data).
- Choosing Capture or Capture Window from the tray menu waits for the menu to close, so it is no longer in the screenshot. Even spacing in the GNOME control window.
- Missing translations filled in; README shortcut and command-line tables updated.

### Linux and packaging

- The AppImage is now built with Qt 6.8 (same as Windows).
- **AUR:** the package runs from an extracted copy in `/opt/eshot` — faster start, no FUSE needed.
- KDE no longer tries to restore EShot from a removed temporary path at login, and startup no longer waits for the service cache rebuild.
- GNOME: the fallback Print Screen shortcut forwards to the running EShot instantly; after installing the tray extension you are told to log in again.
- **Windows installer:** closes EShot gracefully before updating, the Arm64 installer only installs on Arm64, and uninstalling removes downloaded components.
